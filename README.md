## 🛠️ GitHub Pages 활성화 방법
저장소 설정에서 GitHub Pages를 활성화하면 블로그가 라이브로 배포됩니다:
1. 저장소 `Settings` > `Pages` 이동
2. `Build and deployment` > `Source`에서 **Deploy from a branch** 선택
3. `Branch`를 **main** / **/(root)** 로 설정하고 `Save` 클릭!
